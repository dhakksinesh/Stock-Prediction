# Stock Price Prediction Using Machine Learning

A web app that predicts stock price highs and lows using various machine learning and time series models.

## Features
- Live stock data fetched using Yahoo Finance
- Select stocks by country, exchange and name
- Forecast stock high and low prices for a custom horizon
- Compare performance across models using SMAPE

## Models Used
- Simple Exponential Smoothing
- Holt Model
- Holt-Winter Model
- Auto Regressive Model
- Moving Average Model
- ARMA, ARIMA, AutoARIMA
- Linear Regression
- Random Forest
- Gradient Boosting
- Support Vector Machines

## Dataset
- Live stock data fetched from Yahoo Finance
- Stock ticker database covering multiple countries and exchanges

## Technologies Used
